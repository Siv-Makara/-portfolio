MakiPost

Desktop API client · Made in Cambodia 🇰🇭

A fast desktop API client in the spirit of Postman and Bruno. Collections are saved as plain JSON files you can commit to Git, environments make switching servers easy, and you can theme the whole app.

  • Imports Postman collections (v2.0 / v2.1)
  • Supports Bearer, Basic, API Key, Digest and OAuth 2.0 auth, with automatic token refresh
  • Imports and exports cURL commands, keeps request history, and lets you search everything with Ctrl+P
  • Builds for Windows and macOS
